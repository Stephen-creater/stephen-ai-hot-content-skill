# 编辑判断模型

本文件保存从 Stephen 历次审核中萃取出的稳定认知。它回答“如何判断”，不保存当日补丁、具体链接和执行命令。

## 目录

- 一句话目标

## 一句话目标

寻找这样的材料：围绕一个目标读者真正关心的 AI 问题，原文提供足够新的事实与真实取舍，Stephen 能脱离作者专属资产重建论证，并让读者获得具体、持久的行动或认知改变。

## 五个相互独立的维度

### 1. 选题吸引力

先判断“这个题值不值得写”，再判断文章写得好不好。

强信号：

- 普遍存在的生活、学习或工作痛点。
- 有意思且确实有人想用的产品。
- 一个具体矛盾或决策，普通人不需要背景知识就能理解。
- 重大产品变化能自然落到用户任务，而不只是参数、榜单或公司战局。

弱信号：

- 产品本身无趣，只能从“为什么不好用”切入。
- 赛道极窄、受众极少，迁移到大众场景仍然勉强。
- 只讲融资、合作、比赛、跑分、硬件参数或模型身份八卦。
- 宏观命题很大，却找不到一篇文章能持续推进的具体问题。

### 2. 读者改变

合格回答必须具有“之前—之后”结构：读者原来怎么做或怎么想，读完后会改变什么。

有效改变包括：

- 能完成一个此前难以完成的任务。
- 会采用一套可执行的方法或检查方式。
- 会纠正一个影响决策的重要误解。
- 能看懂某种机制，从而更好地选择、使用或评估 AI 产品。

“知道了一个故事”“理解了趋势”“作者很厉害”“自己听完有收获”都不足以证明读者价值。

### 3. 材料增量

材料质量取决于正文提供了什么，不取决于作者名气、篇幅和数字数量。

高质量增量通常来自：

- 作者亲自实践后的失败、调整和结果。
- 围绕同一问题连续展开的完整访谈或演讲。
- 新机制及其适用条件、反例和限制。
- 可核验的具体事实与有条件的取舍。
- 长期实践沉淀出的可复用框架。

低增量常见形态：

- 新闻、官方通稿或翻译只重新排列公开信息。
- QA 回答松散，问题很多但没有连续论证。
- 研究、报告、人物引语和案例拼盘，没有作者自己的判断。
- 工整分类、清单和金句代替了事实与因果链。
- 逐字稿很长、案例很多，但找不到一个足以独立成文的新判断。

### 4. 二创独立性

使用“去身份、去图片、去公司”测试：

1. 隐去作者姓名和职业光环。
2. 移除私人截图、收入、客户资料、品牌宣传图和内部数据。
3. 将专属项目换成公共事实或 Stephen 可亲自验证的材料。

如果核心论证仍完整，真实经历就是证据资产；如果论证随之坍塌，材料与原作者绑定过深。

第一人称、创业经历、企业案例和访谈都不是一票否决。关键在于经验能否抽离成新的、稳定的、可迁移的判断。二创困难时不能通过另拟一个漂亮标题或只取前半篇来假装解决。

还要使用“去媒介”测试。如果去掉视频画面、操作演示或大段代码后，关键步骤、失败与结果就无法理解，那么逐字稿或一个简化切口不能证明它适合文章二创。

### 5. 长期价值

问：新闻刺激消失后，读者是否仍会因为方法、机制或判断回来阅读？

- 发布、故障、价格变化等即时事件通常只在 5 天窗口内有价值。
- 深度访谈、长期实测、机制解释和方法框架可以使用较长窗口。
- 旧材料若只剩“当时发生过”，不再推荐。
- 技术预览、即将破坏性更新的产品和已经被更直接能力替代的绕路方案，长期价值弱。

## 三个重要区分

### 文章质量与适配性

高质量技术文章可能不适合目标读者；低门槛文章也可能因为浅、泛、无新意而不适合。难度不是唯一轴，必须同时判断材料是否提供稀缺、可迁移的框架。

### 作者经验与作者依赖

真实经历通常提升可信度。只有当价值依赖作者身份、私人数据、专属图片或不可复现环境时，它才成为二创障碍。

### 表达信号与实质缺陷

编号、引号、破折号、官方措辞和小标题可以提示 AI 加工或低密度，但不能单独证明作者身份。最终要指出具体缺陷：是否重复、空泛、缺事实、缺因果或没有作者判断。

## 风险信号如何裁决

| 风险信号 | 必须继续核实的问题 |
|---|---|
| 技术词很多 | 理解主线是否必须掌握这些词？能否低成本解释而不损失论证？ |
| 个人经历很多 | 去掉私人资产后，是否还有可迁移的因果链？ |
| 访谈或逐字稿 | 是否围绕一个问题推进，还是人生闲聊与宏观判断？ |
| 新闻或官方来源 | 是否有独立实践、判断和可复用机制？ |
| 产品介绍 | 产品是否值得关注？是否存在独立证据而非品牌宣传？ |
| 工整结构或 AI 味 | 结构背后是否有具体事实、失败和条件？ |
| 图片很多 | 文字论证离开图片能否独立成立？ |
| 垂直行业 | 普通读者是否有真实需求，还是只能硬抽象出一个通用切口？ |

## 决策纪律

- 自动分数只决定先读什么，不能决定最后推荐什么。
- 每项通过判断都要引用正文事实，不接受“深度好文”“作者权威”等空结论。
- 必须写最强反对理由，再说明为什么仍然放行。
- “勉强能过”按不通过处理；不得为凑数量降低标准。
- 待定是独立状态，不算正负反馈。
- 已写、已审和并发任务已交付的主题，优先级高于按钮的表面入选状态。
- 用户只有按钮没有备注时，记录结果但不推断原则。
- 新反馈先经过学习协议，不直接写成关键词或类别禁令。
